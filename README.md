#Route Finder
This optimizes the route from location to destination using "ML" and "Graph Algorithms"
The project predicts traffic speed using a Decision Tree Regression model and computes the shortest travel-time path using Dijkstra's Algorithm. The application is deployed through a Streamlit web interface.

#Features
- Predicts vehicle speed using Machine Learning
- Builds a road network using NetworkX
- Calculates the fastest route using Dijkstra's Algorithm
- Interactive Streamlit interface
- Visualizes the road network and optimal route
- Modular Python project structure

#Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NetworkX
- Matplotlib
- Streamlit
- Joblib
